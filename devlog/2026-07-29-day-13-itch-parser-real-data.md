## 2026-07-29 — real ITCH 5.0 parser, verified against real Nasdaq data

Started closing the biggest gap flagged in ROADMAP.md: everything upstream of the matching engine. First piece is the Feed Handler's message parser.

Pulled the actual Nasdaq TotalView-ITCH 5.0 spec (nasdaqtrader.com, revision log's most recent entry: April 28, 2023 — the doc's still titled "5.0" but covers 23 message types, not the ~20 most references cite; Nasdaq added LULD Auction Collar, Operational Halt, and Direct Listing with Capital Raise later without bumping the version string). Transcribed every field's exact offset/length/encoding from the spec, not from a secondhand parser — including the traps: Operational Halt's type code is lowercase `'h'` (every other type is uppercase), Cross Trade's Shares field is 8 bytes where every other message's is 4, Order Replace doesn't carry side/stock/attribution at all (caller has to track that from the original Add Order), and Trade message's Order Reference Number and Buy/Sell Indicator have been meaningless zero/always-'B' fields since 2010 and 2014 respectively.

Got real data to check it against: downloaded `12302019.NASDAQ_ITCH50.gz` (3.5GB) from Nasdaq's own historical archive, trimmed to a 20MB real excerpt (matching the existing LOBSTER sample's scale), decoded the first message by hand against the spec before writing any parsing code — `00 0c 53 00 00 00 00 0a 11 ea 0e 8c 43 4f` is a System Event, type 'S', event code 'O' (Start of Messages), exactly what a real trading day's first message should be. That also confirmed the historical file framing: a 2-byte big-endian length prefix per message (Nasdaq's "BinaryFile" protocol — distinct from MoldUDP64, which frames the live multicast feed, not the downloadable replay files).

Parser + BinaryFile reader verified against the full 20MB sample: 691,421 real messages, all 23 types recognized, zero length mismatches between the wire's length prefix and each type's spec-declared size, first-message check passes. Histogram is exactly what a real exchange-open sequence should look like — 215K Market Participant Position and ~8,900 each of Stock Directory/Trading Action/Reg SHO (one per listed symbol) dominate, since this slice is the early reference-data phase before regular trading volume ramps up.
